# 틱네이션 (TikNation)

틱톡 LIVE 선물·채팅으로 마인크래프트와 방송 화면을 움직이는 Windows용 방송 도우미예요.
마크 명령, TTS 채팅 읽기, OBS 오버레이를 앱 하나로 써요.

- 웹사이트: https://tiknation.rntjs.cloud/
- 사용 가이드: https://tiknation.rntjs.cloud/guide/
- 틱톡 리그 조회: https://tiknation.rntjs.cloud/league/
- 내려받기: [최신 버전](https://github.com/taetae0110/tiknation/releases/latest) (Windows 10 · 11, 64비트)

이 저장소는 틱네이션 업데이트 파일을 올리는 곳이에요.
